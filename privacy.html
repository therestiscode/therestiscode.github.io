Privacy

Last updated 22 September 2026

This site sets no cookies and collects nothing about its visitors.

The Rest is Code uses its own internal tools, signed in with Google and granted read-only access, to read the channel's own YouTube data and analytics. That data is used only to improve the channel's videos. It is never sold, never used for advertising, and never shared except with service providers that process it on the channel's behalf.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
